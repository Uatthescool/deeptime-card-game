REFERENCE AND SOURCES
reference/ contains original comparison artwork, master frames and the Jurassic fossil texture used as the color source.
sources/ contains deterministic build scripts. The icon scripts find Node and sharp through the NODE
and SHARP environment variables (default: "node" and "sharp"); the texture scripts read the Jurassic
texture from C:/Dev/prehistoric-card-game. Adjust paths and output directories before running
elsewhere. No image generation was used.
The final exported files in icons/ and textures/ are ready to use without running any script.

Shared frame geometry remains unchanged. No game files or live card layouts have been modified.
Superseded design alternatives and intermediate ZIPs are omitted from this current support asset kit.
MANIFEST.json lists every packaged source asset and its SHA-256 checksum.
